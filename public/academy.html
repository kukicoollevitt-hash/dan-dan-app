브레인 문해력 궁금증을 해결해보아요

Q1 부모가 많이 도와줘야 하나요?
👉 아니요. 최소 개입 구조입니다
  • 부모/교사 역할: 칭찬 · 격려 · 체크
  • 학습 설계와 보완은 👉 AI가 자동으로 진행
Q2 AI가 아이 수준을 정확히 파악하나요?
👉 가능합니다
  • 이해력 / 어휘 / 문맥 / 적용력 분석
  • 부족한 부분만 선별
  • 👉 맞춤형 반복 학습 설계
Q3 단순히 많이 읽는 프로그램인가요?
👉 아닙니다
  • 목표: '제대로 이해하기'
  • 구성: 배경지식 웹툰 → 문맥 기반 어휘 → 단계별 평가
  • 👉 읽기 → 이해 중심 구조
Q4 아이가 중간에 포기하지 않나요?
👉 지속 학습 구조입니다
  • 웹툰 → 형성평가 → 승급평가
  • 👉 단계별 성취 경험 제공
Q5 평가가 많으면 부담되지 않나요?
👉 부담이 아닌 보완 과정입니다
  • 줄 세우기 시험 ❌
  • 부족한 부분 확인 → 보완 설계 ⭕
Q6 문해력 하나로 다른 과목도 도움 되나요?
👉 모든 과목의 기반입니다
  • 국어뿐 아니라 👉 수학 · 과학 · 사회까지 영향
  • 이해 부족으로 틀리는 문제 감소
Q7 언제부터 효과가 나타나나요?
👉 초기부터 변화 체감 가능
  • 문제 이해 속도 ↑
  • 어휘 사용 ↑
  • 설명력 ↑
