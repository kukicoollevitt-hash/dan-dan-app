🎯 단원 만점400점4문단 모두 정답
오답 시 빈칸이 재배치되고 카드풀에 일시적 차단이 걸려요. 무작위 시도를 방지하고 지문을 다시 읽는 시간이에요.

등수보너스

🥈 2위+50점
🥉 3위+30점
4~10위+20점
11위~+10점

③ 등수 변동 시 점수 차이

변동점수 차이
🥇 → 🥈 (1위 강등)-50점
🥈 → 🥉 (2위 강등)-20점
🥉 → 4위 (3위 강등)-10점
10위 → 11위-10점
추격 효과 — 새 학생이 등수에 진입하면:
시나리오추격자기존격차
🥇 1등 추격+100-50-150
🥈 2등 진입+50-20-70
🥉 3등 진입+30-10-40
1등 추격 시 격차 150점이 한 번에 좁혀져요! 단원별 등수 보너스 변동이라 모든 단원에서 발생.

④ 단원 기여 점수 = 점수 + 등수 보너스

예 1) 400점 + 1위500점
예 2) 370점 + 4위390점
예 3) 200점 + 11위210점
점수 + 등수 보너스 가 각 단원의 기여 점수. 모든 단원의 기여 점수 합이 전체 종합 점수가 돼요.
